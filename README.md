# Automação de Testes - Site SC.SENAI.BR

Projeto de **automação E2E** usando **Cypress** para o site [sc.senai.br](https://sc.senai.br), garantindo qualidade, visibilidade de elementos e funcionamento correto de interações em todo o site.

---

## 🔹 Objetivo

Automatizar testes para o site completo, incluindo:

- Páginas institucionais e seções internas.
- Funcionalidades de formulários e links externos.
- Validação de URLs internas e redirecionamentos.
- Validação dos componentes.
- Testes de responsividade.

## 📥 Como baixar e rodar o projeto

### 1️⃣ Clonar o repositório
```bash
git clone https://github.com/AlineEspindola/senai-sc-tests
```

### 2️⃣ Entrar na pasta do projeto
```bash
cd senai-sc-tests
```

### 3️⃣ Instalar as dependências
```bash
npm install
```

### 4️⃣ Abrir Cypress em modo interativo
```bash
npx cypress open
```

### ou, para rodar os testes em modo headless (sem interface)
```bash
npx cypress run
```
